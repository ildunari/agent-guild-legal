# Agent Guild legal pages

Public Privacy Policy and Support pages for the **Agent Guild** iOS app.

Hosted on GitHub Pages so App Store and in-app links return HTTP 200 when you are logged out of GitHub. This repository is public on purpose. Do not put tokens, passwords, private-repo links, or other secrets here.
